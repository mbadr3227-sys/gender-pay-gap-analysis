
## Running the Analysis

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook notebooks/01_gender_pay_gap_analysis.ipynb
```

## Data Source

[Glassdoor Gender Pay Gap](https://www.kaggle.com/datasets/nilimajauhari/glassdoor-analyze-gender-pay-gap) (Kaggle) — 1,000 employee records.

## Limitations

This is a synthetic dataset created for educational purposes. It lacks tenure,
contracted hours, part-time status and location — variables that materially
affect real pay gap analysis. The project demonstrates analytical method rather
than describing any actual organisation.
